# Документация: Работа с пользователями в приложении

Этот модуль предназначен для работы с пользователями в приложении. Он позволяет регистрировать пользователей, входить в систему, выходить и сохранять информацию о пользователях. Если вы хотите интегрировать функциональность работы с пользователями, эта документация поможет вам разобраться в основных функциях и их использовании.

## 1.  Регистрация пользователя

Эта функция регистрирует нового пользователя в системе, создавая учетную запись с указанными email, password и username. После успешной регистрации, данные пользователя сохраняются в базе данных Firestore.

```
AuthService.shared.register(email: String, password: String, username: String, completion: @escaping (Result<AuthDataResult, Error>) -> Void)

```

### Параметры
** email: Адрес электронной почты пользователя.
** password: Пароль для учетной записи.
** username: Имя пользователя.

### Возвращает:
** Результат с объектом AuthDataResult при успешной регистрации.
** Ошибку, если регистрация не удалась.




## 1.2 Вход пользователя

Эта функция позволяет пользователю войти в систему, используя свой email и password. 
Автоматически сохраняется userID в UserDefaults.

```
AuthService.shared.signIn(email: String, password: String, completion: @escaping (Result<AuthDataResult, Error>) -> Void)

```

### Параметры
** email: Адрес электронной почты пользователя.
** password: Пароль для учетной записи.

### Возвращает:
** Результат с объектом AuthDataResult при успешной регистрации.
** Ошибку, если регистрация не удалась.




## 1.3 Выход пользователя

Эта функция выполняет выход пользователя из системы.
Автоматически удаляется userID из UserDefaults.

```
AuthService.shared.signOut(completion: @escaping (Result<Void, Error>) -> Void)

```

### Возвращает:
** Успех, если выход выполнен успешно.
** Ошибку, если выход не удался.




## 1.4 Сохранение профиля пользователя

Эта функция сохраняет username и email пользователя в базе данных Firestore.

```
UserService.shared.saveUserProfile(uid: String, email: String, username: String, completion: @escaping (Result<Void, Error>) -> Void)

```

### Параметры
** uid: Уникальный идентификатор пользователя.
** email: Адрес электронной почты пользователя.
** username: Имя пользователя.

### Возвращает:
** Успех, если данные успешно сохранены.
** Ошибку, если сохранение не удалось.




## 1.5 Сохранение произвольных данных пользователя

Эта функция позволяет сохранять произвольные данные пользователя под заданными ключами.

```
UserService.shared.saveUserData(uid: String, data: [String: Any], completion: @escaping (Result<Void, Error>) -> Void)

```

### Параметры
** uid: Уникальный идентификатор пользователя.
** data: Словарь с данными для сохранения.

### Возвращает:
** Успех, если данные успешно сохранены.
** Ошибку, если сохранение не удалось.


### Пример:
```
let userData: [String: Any] = [
    "username": "exampleUser", - По умолчанию должен быть у пользователя
    "email": "example@example.com", - По умолчанию должна быть у пользователя
    "age": 25,
    "profilePictureURL": "http://example.com/profile.jpg"
]

UserService.shared.saveUserData(uid: "user123", data: userData) { result in
    switch result {
    case .success:
        print("Данные пользователя успешно сохранены.")
    case .failure(let error):
        print("Ошибка при сохранении данных: \(error.localizedDescription)")
    }
}
```



## 1.6 Получение данных пользователя

Эта функция позволяет извлекать данные пользователя из базы данных Firestore по уникальному идентификатору.

```
UserService.shared.fetchUserData(uid: String, completion: @escaping (Result<[String: Any], Error>) -> Void)

```

### Параметры
** uid: Уникальный идентификатор пользователя.

### Возвращает:
** Словарь с данными пользователя при успешном получении.
** Ошибку, если данные не были найдены или произошла ошибка.



### Пример:
```
fetchUserData(uid: "exampleUserID") { result in
    switch result {
    case .success(let userData):
        if let username = userData["username"] as? String, let email = userData["email"] as? String {
            print("Имя пользователя: \(username), Email: \(email)")
        }
    case .failure(let error):
        print("Ошибка при получении данных пользователя: \(error.localizedDescription)")
    }
}
```


## 2. Хранение идентификатора пользователя

При успешной авторизации пользователя его уникальный идентификатор (UID) сохраняется в локальном хранилище с помощью UserDefaults. Это позволяет легко получить доступ к идентификатору пользователя в будущем, не требуя повторной авторизации. При деавторизации, ключ пользователя автоматичски удаляется.




## 2.1 Получение идентификатора пользователя:

Для доступа к сохранённому идентификатору пользователя нужно использовать следующую команду:

```
UserDefaults.standard.object(forKey: "userID")

```
