# Крестики-нолики | News Today
IOS app where the user is able to view the most popular news as well as a news feed divided into categories.
</br></br>
IOS-приложение, в котором пользователь может просматривать самые популярные новости, а также новостную ленту, разделенную на категории.

## Demo | Демо


## Technologies | Технологии
- XCode
- Foundation
- UIKit
- UserDefaults
- Firebase
- Kingfisher

## Usage | Использование
1. Clone the project via XCode, Terminal or any other method | Клонируйте проект с помощью XCode, терминала или любым другим способом
2. While cloning choose "develop" branch | При клонировании выберите ветку "develop"
3. Run on IPhone Simulator with IOS 15+ | Запустите на симуляторе iPhone с IOS 15+
